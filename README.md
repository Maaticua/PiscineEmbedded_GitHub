# Piscine Embedded

## Overview
An intensive deep dive into bare-metal embedded systems programming.
This project focuses on interacting directly with microcontrollers without an operating system,
providing a robust foundation in low-level hardware architecture.

## Tech Stack
* **Language:** C (Bare-Metal)
* **Concepts:** Microcontrollers, Register manipulation, Interrupts handling, Serial Bus Protocols (UART, I2C, SPI),
Hardware Timers.

## Features
* Direct hardware manipulation and configuration.
* Implementation of standard serial communication protocols from scratch.
* Event-driven programming via hardware interrupts.
